Balatro in VR - File names for your own joker models
=====================================================

How it works:
- Put a 3D model (.glb or .gltf) into the folder
    %APPDATA%\Godot\app_userdata\Balatro in VR\custom_jokers\
  or into a folder "custom_jokers" right next to Balatro in VR.exe.
- The file must be named exactly like the key in the first column, e.g. j_popcorn.glb.
  Leaving out the "j_" works too (popcorn.glb). All lower case, underscores instead of spaces.
- Careful, a few keys are spelled differently from the joker's name in the game itself:
    Seltzer = j_selzer, Mr. Bones = j_mr_bones, Riff-raff = j_riff_raff, Seance = j_seance,
    Joker Stencil = j_stencil, Cloud 9 = j_cloud_9, Golden Ticket = j_ticket,
    Gluttonous Joker = j_gluttenous_joker (sic), ...
  So always use the key from this list, not the name shown in the game.
- Optional: a .json file with the same name next to it, e.g. j_popcorn.json:
    {"height": 0.15, "rotation": [0, 90, 0]}
  (height in metres, default 0.11; rotation in degrees around X, Y, Z).
- Your model replaces the joker's figure the next time the game starts.
- "VR: 3D Jokers: Custom Only" (VR Settings) shows only your own figures; all other jokers
  stand on their pedestal as cards.
